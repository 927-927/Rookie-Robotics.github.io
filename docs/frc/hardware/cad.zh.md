# CAD { #cad }

CAD（计算机辅助设计）就是在真正动手造机器人之前，先在电脑上把它搭出来。一个完整的 CAD 模型能告诉你零件是否装得下、每个电机和每根线放在哪里、每个机构能动多远，而这时改动只需要点几下鼠标。它还能给制造组提供精确的图纸和文件，用来切割、打印和钻孔。

大多数 FRC 队伍用 [Onshape](https://www.onshape.com/) 做设计。它在网页浏览器里运行，所以任何一台学校的笔记本电脑都能用，什么都不用安装。整个队伍可以同时编辑同一个文档。而且在 Onshape 的教育计划下，学生和老师都可以免费使用。

## 用 FRCDesign.org 学习 { #learn-with-frcdesignorg }

[FRCDesign.org](https://frcdesign.org/) 是一个免费的课程和参考网站，教你用 Onshape 设计 FRC 机器人。学 CAD 就去这里：课程从零开始，最后能建模一整台机器人；网站的其他部分是设计时随时回来查的参考资料。

### 学习课程 { #the-learning-course }

| 部分 | 学什么 |
|---|---|
| [Course Setup（课程准备）](https://frcdesign.org/learning-course/course-setup/new-to-cad/) | 选择你的起点（没用过 CAD，或者没用过 Onshape），注册 Onshape 账号，并添加课程要用的工具。每个人都要完成 *Required Course Tools* 这一页。 |
| [Stage 1（第一阶段）](https://frcdesign.org/learning-course/stage1/1a/section1-setup/) | 草图、零件、多零件模型和装配体。动力传动和齿轮箱。建模一个舵轮底盘，并开始自顶向下设计。 |
| [Stage 2（第二阶段）](https://frcdesign.org/learning-course/stage2/2a/introduction/) | 常见的 FRC 机构和背后的工程原理，每个都配一张布局草图，直到你能熟练使用 Onshape。 |
| [Next Steps（下一步）](https://frcdesign.org/learning-course/next-steps/) | 你自己的机器人和机构项目、获取设计反馈，以及研究其他队伍公开的 CAD。 |

## 从哪里开始 { #where-to-start }

1.  **注册一个 Onshape 账号**，选择免费的教育计划。课程准备里的 *New to Onshape* 部分会一步步带你完成。
2.  **阅读 [Website Feature Guide](https://frcdesign.org/feature-guide/)。**只需要几分钟，而课程会经常用到里面讲的下拉框和按钮。
3.  **按顺序完成学习课程。**不要跳过任何小节或练习，即使你用过其他 CAD 软件：Onshape 的底层工作方式不一样，而且后面的阶段都建立在前面每一个阶段之上。如果觉得简单，自然会很快做完。
4.  **设计时把 Design Handbook 和 Mechanism Examples 开着。**它们是用来查东西的参考资料，不是要从头读到尾的课程。

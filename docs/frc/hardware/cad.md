# CAD

CAD (computer-aided design) is building the robot on a computer before
building it for real. A full CAD model shows whether parts fit, where every
motor and wire goes, and how far each mechanism moves, while changes still
only cost a few clicks. It also gives the build team exact drawings and files
to cut, print and drill from.

Most FRC teams design in [Onshape](https://www.onshape.com/). It runs in a web
browser, so it works on any school laptop with nothing to install. A whole
team can edit the same document at once. And it's free for students and
teachers on Onshape's education plan.

## Learn with FRCDesign.org

[FRCDesign.org](https://frcdesign.org/) is a free learning course and
reference for designing FRC robots in Onshape. It is where to learn CAD: the
course starts from zero and ends with modeling a full robot, and the rest of
the site is a reference to come back to while designing.

### The Learning Course

| Part | What you learn |
|---|---|
| [Course Setup](https://frcdesign.org/learning-course/course-setup/new-to-cad/) | Pick your starting point (new to CAD, or new to Onshape), make an Onshape account, and add the tools the course uses. Everyone does the *Required Course Tools* page. |
| [Stage 1](https://frcdesign.org/learning-course/stage1/1a/section1-setup/) | Sketches, parts, multi-part models and assemblies. Power transmission and gearboxes. Model a swerve drivebase, and start designing top-down. |
| [Stage 2](https://frcdesign.org/learning-course/stage2/2a/introduction/) | Common FRC mechanisms and the engineering behind them, with a layout sketch for each, until you're comfortable in Onshape. |
| [Next Steps](https://frcdesign.org/learning-course/next-steps/) | Your own robot and mechanism projects, getting design feedback, and studying other teams' public CAD. |

## Where to start

1.  **Make an Onshape account** on the education plan, which is free. The
    *New to Onshape* part of the course setup walks you through it.
2.  **Read the [Website Feature Guide](https://frcdesign.org/feature-guide/).**
    It takes a few minutes, and the course relies on its dropdowns and
    buttons.
3.  **Do the Learning Course in order.** Don't skip sections or exercises,
    even if you've used other CAD software: Onshape works differently
    underneath, and later stages build on every earlier one. If it's easy, it
    will go fast.
4.  **Keep the Design Handbook and Mechanism Examples open while you design.**
    They're a reference to look things up in, not a course to read through.

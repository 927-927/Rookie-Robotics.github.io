# 基于命令的基本结构 { #command-based-skeleton }

一个基于命令（command-based）的机器人的基本结构：命令、命令所使用的机构，以及启动命令的触发器。可以跟着 frcsoftware.org 学习课程的 **Stage 1B** 来学。它一次搭建一个部分，最后把一台基于时间的套件机器人（kitbot）改写成基于命令的。

[:octicons-arrow-right-24: 在 frcsoftware.org 上开始 Stage 1B](https://frcsoftware.org/learning-course/stage1/stage1b/stage-overview/){ .md-button .md-button--primary }

## 课程 { #lessons }

Stage 1B 建立在 [Stage 1A](https://frcsoftware.org/learning-course/stage1/stage1a/stage-overview/) 的套件机器人代码之上，所以要先学 Stage 1A。然后按顺序学习：

1.  [The Concepts](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-overview/)（基本概念）
2.  [The Body of a Command](https://frcsoftware.org/learning-course/stage1/stage1b/the-command-body/)（命令的主体）
3.  [Commands & Mechanisms, Pt. 1](https://frcsoftware.org/learning-course/stage1/stage1b/commands-and-mechanisms/)（命令与机构，第 1 部分）
4.  [Triggers and Scheduling](https://frcsoftware.org/learning-course/stage1/stage1b/triggers/)（触发器与调度）
5.  [Commands & Mechanisms, Pt. 2](https://frcsoftware.org/learning-course/stage1/stage1b/commands-and-mechanisms-pt2/)（命令与机构，第 2 部分）
6.  [Bonus: Spot the Error](https://frcsoftware.org/learning-course/stage1/stage1b/spot-the-error/)（附加：找错误）
7.  [Exercise - Kitbot Rewrite, Pt. 1](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-kitbot/)（练习：改写套件机器人，第 1 部分）
8.  [Suppliers in Command-Based](https://frcsoftware.org/learning-course/stage1/stage1b/suppliers-in-command-based/)（基于命令中的 Supplier）
9.  [Exercise - Kitbot Rewrite, Pt. 2](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-kitbot-pt2/)（练习：改写套件机器人，第 2 部分）
10. [Bonus: Spot the Error, Pt 2](https://frcsoftware.org/learning-course/stage1/stage1b/spot-the-error-pt2/)（附加：找错误，第 2 部分）

!!! note "Commands v3"

    Stage 1B 教的是 **Commands v3**，这是 WPILib 2027 新推出的版本，它的代码只能在 Systemcore 上或仿真中运行。本站的[从基于时间到基于命令](time-based-to-command-based.md)使用的是 roboRIO 上的 Commands v2，并且[列出了两者的区别](time-based-to-command-based.md#commands-v3)。

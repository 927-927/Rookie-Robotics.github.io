# Command-based skeleton

The basic structure of a command-based robot: commands, the mechanisms they
use, and the triggers that start them. Learn it with **Stage 1B** of
frcsoftware.org's learning course. It builds the structure up one piece at a
time, and ends with rewriting a time-based kitbot as command-based.

[:octicons-arrow-right-24: Start Stage 1B on frcsoftware.org](https://frcsoftware.org/learning-course/stage1/stage1b/stage-overview/){ .md-button .md-button--primary }

## Lessons

Stage 1B builds on the kitbot code from
[Stage 1A](https://frcsoftware.org/learning-course/stage1/stage1a/stage-overview/),
so do that first. Then do the lessons in order:

1.  [The Concepts](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-overview/)
2.  [The Body of a Command](https://frcsoftware.org/learning-course/stage1/stage1b/the-command-body/)
3.  [Commands & Mechanisms, Pt. 1](https://frcsoftware.org/learning-course/stage1/stage1b/commands-and-mechanisms/)
4.  [Triggers and Scheduling](https://frcsoftware.org/learning-course/stage1/stage1b/triggers/)
5.  [Commands & Mechanisms, Pt. 2](https://frcsoftware.org/learning-course/stage1/stage1b/commands-and-mechanisms-pt2/)
6.  [Bonus: Spot the Error](https://frcsoftware.org/learning-course/stage1/stage1b/spot-the-error/)
7.  [Exercise - Kitbot Rewrite, Pt. 1](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-kitbot/)
8.  [Suppliers in Command-Based](https://frcsoftware.org/learning-course/stage1/stage1b/suppliers-in-command-based/)
9.  [Exercise - Kitbot Rewrite, Pt. 2](https://frcsoftware.org/learning-course/stage1/stage1b/command-based-kitbot-pt2/)
10. [Bonus: Spot the Error, Pt 2](https://frcsoftware.org/learning-course/stage1/stage1b/spot-the-error-pt2/)

!!! note "Commands v3"

    Stage 1B teaches **Commands v3**, new in WPILib 2027, and its code runs
    only on a Systemcore or in simulation.
    [Time-based to command-based](time-based-to-command-based.md) on this site
    uses Commands v2, for the roboRIO, and
    [lists what's different](time-based-to-command-based.md#commands-v3).

# Java 基础 { #java-basics }

机器人代码是用 Java 写的。如果你刚接触 Java 或者编程，可以跟着 frcsoftware.org 学习课程的 **Stage 0** 来学。它教的是写 FRC 机器人代码需要的 Java，每次一节短课。

[:octicons-arrow-right-24: 在 frcsoftware.org 上开始 Stage 0](https://frcsoftware.org/learning-course/stage0/stage-overview/){ .md-button .md-button--primary }

## 课程 { #lessons }

frcsoftware.org 是英文网站，下面的课程名保留了英文原名。上第一节课之前，先按照 [Required Tools](https://frcsoftware.org/learning-course/getting-started/required-tools/)（必备工具）和 [Getting Started](https://frcsoftware.org/learning-course/)（入门）的其他部分把电脑设置好。然后按顺序学习：

1.  [Java Fundamentals](https://frcsoftware.org/learning-course/stage0/java-fundamentals/)（Java 基础知识）
2.  [Debugging](https://frcsoftware.org/learning-course/stage0/debugging/)（调试）
3.  [Git - Uploading Code](https://frcsoftware.org/learning-course/stage0/git/)（Git：上传代码）
4.  [Operators](https://frcsoftware.org/learning-course/stage0/operators/)（运算符）
5.  [Conditionals](https://frcsoftware.org/learning-course/stage0/conditionals/)（条件语句）
6.  [Loops](https://frcsoftware.org/learning-course/stage0/loops/)（循环）
7.  [Classes and Objects](https://frcsoftware.org/learning-course/stage0/classes-objects/)（类和对象）
8.  [Methods and Mutable State](https://frcsoftware.org/learning-course/stage0/classes-methods/)（方法和可变状态）
9.  [Arrays and For-Each Loops](https://frcsoftware.org/learning-course/stage0/arrays/)（数组和 for-each 循环）
10. [Interfaces, Generics, and Lists](https://frcsoftware.org/learning-course/stage0/interfaces-lists/)（接口、泛型和列表）

想要更多练习，可以看 Stage 0 的 [Additional Resources](https://frcsoftware.org/learning-course/stage0/additional-resources/)（补充资源）。

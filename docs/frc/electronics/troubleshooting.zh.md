# 故障排查 { #troubleshooting }

设备不工作时，先做最快的检查，通过了再进行下一步：先看状态灯，再用万用表测量，最后拆分总线。这一页讲的是 CAN 总线，大多数接线问题都出在这里。

## 先看状态灯 { #start-with-the-status-lights }

每个 CAN 设备都有状态灯。在 Kraken X60 这样的 CTRE 设备上，主要的代码是：

<div class="lights" markdown>

| 灯 | 含义 |
|---|---|
| <span class="leds"><i class="led"></i><i class="led"></i></span> 不亮 | 没有电。检查断路器和红黑线。 |
| <span class="leds"><i class="led red-off"></i><i class="led red-off late"></i></span> 红色 | 没有 CAN。继续往下看。 |
| <span class="leds"><i class="led orange-off"></i><i class="led orange-off"></i></span> 橙色 | CAN 正常，机器人禁用。 |
| <span class="leds"><i class="led green-off"></i><i class="led green-off"></i></span> 绿色 | CAN 正常，机器人启用。 |

</div>

每个设备的完整列表见[常用设备](../hardware/devices.md)。红灯从哪里开始亮，就告诉你该往哪里找：

- **只有部分设备闪红灯。**从 roboRIO 开始沿着总线找：故障通常就在第一个红灯设备之前。一根断线会让它后面的所有设备都断开。
- **所有设备都闪红灯。**故障可能在任何地方。有东西把整条总线拖垮了，比如黄绿线碰在一起，或者某个设备坏了。[拆分总线](#split-the-bus)来找到它。

## 用万用表检查总线 { #check-the-bus-with-a-multimeter }

万用表测量的是线路本身，所以它能找到那些机器人一震动才会出现的故障。测量时**机器人要断电**：测电阻时万用表会自己输出一个小电流，机器人的电会干扰读数。

黑表笔插 **COM** 孔，红表笔插标着 **Ω** 的孔（通常和 V 共用）。你需要的两个档位是：

| 档位 | 符号 | 显示 |
|---|---|---|
| 电阻档 | Ω | 两支表笔之间的电阻。**OL** 表示太大测不出来，或者根本没接通。 |
| 通断档 | :material-volume-high:（声波） | 两支表笔之间被导线接通、电阻约为 0 Ω 时会鸣响。 |

### 测量终端电阻 { #measure-the-resistors }

CAN 总线两端各有一个 120 Ω 电阻。在黄绿线之间测量，两个并联的 120 Ω 电阻读数是 **60 Ω**。

<div class="can-sim" data-scene="resistance" markdown>

1. 机器人断电，把万用表调到 **Ω** 档。表笔什么都不碰时，读数是 OL。
2. 一支表笔接黄线，一支接绿线，在总线上任何位置都可以。正常的总线读数约为 **60 Ω**。这条读数是 **120 Ω**：万用表只测到了两个电阻中的一个。
3. 拔下末端的电阻单独测量。读数是 **120 Ω**，说明电阻是好的。那就是两端之间有一根线断了：接下来[找断线](#look-for-a-broken-wire)。

</div>

| 总线读数 | 含义 | 怎么做 |
|---|---|---|
| 约 60 Ω | 两个电阻都在 | 它们之间的线路很可能没问题。在 Phoenix Tuner X 里检查设备 ID、供电和固件。 |
| 约 120 Ω | 只有一个电阻：末端电阻缺失或损坏，或者两端之间有一根线断了 | 单独测量末端电阻。如果是 120 Ω，就去[找断线](#look-for-a-broken-wire)。 |
| 约 40 Ω | 有三个电阻：中间某处多了一个，或者中间的 PDH 把 TERM 拨到了 ON | 找到多出来的那个并去掉。 |
| 接近 0 Ω | 黄绿线在某处碰在了一起 | [拆分总线](#split-the-bus)来找到位置。 |
| OL | 一个电阻都没有，或者表笔没接触到裸露的金属 | 检查表笔，然后检查总线的两端。 |

### 找断线 { #look-for-a-broken-wire }

通断档能找出是哪根线断了、断在哪里。末端电阻保持拔下：如果插着，万用表会绕过断点，经过两个电阻和另一根线形成通路，读数约为 240 Ω 而不是 OL。

<div class="can-sim" data-scene="continuity" markdown>

1. 机器人保持断电，末端电阻保持拔下。把万用表调到**通断档**。
2. 一支表笔接总线起点的黄线，另一支接末端的黄线。万用表鸣响：黄线是通的。
3. 再测绿线，起点和末端。不响，读数是 **OL**：绿线在中间某处断了。
4. 一支表笔留在起点，另一支一个接头一个接头地往回移。到 J3 还是 OL。
5. 到 J2 时鸣响了，所以断点在 J2 和 J3 之间。这里是 Kraken 3 旁边的一个压接脱落了。
6. 把线修好，插回末端电阻，再用 **Ω** 档测量总线：**60 Ω**。

</div>

- 如果要从机器人的一头量到另一头，用鳄鱼夹在一支表笔上夹一根长线。
- 如果故障时有时无，把万用表留在通断档，一根一根、一个接头一个接头地晃动线。鸣响中断的地方就是坏点。
- 断点最常出现在压接处、线没完全插到底的 Wago 里，或者线蹭到锋利边缘或运动部件的地方。

## 拆分总线 { #split-the-bus }

当所有设备都闪红灯，或者万用表什么都没找到时，在机器人**通电**的情况下把总线从中间拆开，观察电机的灯。每拆一次，要检查的总线范围就减半，所以即使总线很长，也只需要拆几次。

<div class="can-sim" data-scene="split" markdown>

1. 每个 Kraken 都闪红灯：总线上没有任何设备能和 roboRIO 通信。
2. 打开中间的接头 J2。Kraken 1 和 2 变成橙色：它们这一半总线是好的，所以故障在 J2 后面。
3. 接上 J2，打开 J3，也就是坏的那一半的中间。Kraken 1 到 3 变成橙色：故障在 J3 后面。
4. 只剩下 Kraken 4 和它的线了。这里是它的黄绿线被压在了一起。
5. 修好线，接上 J3。每个 Kraken 都闪橙灯。

</div>

- **只看打开的接头靠 roboRIO 那一侧的设备。**另一侧的设备不管怎样都会闪红灯，因为它们被断开了。
- **如果 roboRIO 那一侧还是红灯，**故障就在这一侧。接上这个接头，改为打开往 roboRIO 方向一半位置的接头。
- **在 Wago 处拆分：**它们不用工具就能打开。这也是总线在子系统之间用 Wago 的原因之一（见[信号接线](signal-wiring.md#how-to-wire)）。
- 打开一个接头后，roboRIO 那一半只有一端有电阻。总线短的话，测试时这样通常也能工作。如果它的灯一直是红的，先在打开的接头处给黄绿线之间临时接一个备用的 120 Ω 电阻，再判断故障是不是在这一侧。
- 如果故障缩小到了一个设备上，而它的线看起来没问题，可能是设备本身坏了。换一个备用的来确认。

更多检查方法，比如在 Phoenix Tuner X 里读取总线信息，见 CTRE 的 [CAN bus troubleshooting](https://v6.docs.ctr-electronics.com/en/stable/docs/troubleshooting/canbus-troubleshooting.html)（CAN 总线故障排查）。
